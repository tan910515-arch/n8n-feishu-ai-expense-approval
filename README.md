# 🤖 飞书智能财务审批自动化工作流 (n8n + DeepSeek)

基于 **n8n** 和 **DeepSeek大模型** 构建的企业级报销审批自动化流。该项目模拟了真实企业场景，实现了“表单填写 -> AI 智能判断 -> 飞书群机器人实时分流通知”的完整闭环。

## ✨ 核心功能
*   **极简表单触发**：员工通过 n8n Form 填报销单（申请人、金额、类别、事由）。
*   **AI 智能决策**：接入 DeepSeek 模型，自动识别金额和类别（如：>500元或招待费需审批）。
*   **数据清洗与结构化**：通过 JS 代码节点剥离 LLM 的 Markdown 标记，强制输出标准 JSON 格式。
*   **精准分流**：根据 AI 判断，自动分流为“待审批”（推送至飞书等待人工介入）和“已自动通过”（小额直接放行记录）。
*   **飞书系统集成**：通过 HTTP Request 调用飞书 Webhook，实现实时消息推送。

## 🛠️ 技术栈与踩坑指南 (实战经验)
*   **工作流引擎**：n8n
*   **大语言模型**：DeepSeek-Chat (通过 OpenAI 兼容接口接入)
*   **集成工具**：飞书自定义机器人

**💡 踩坑记录（面试可聊）：**
1.  **LLM 输出被包裹**：大模型输出文本常带有 ` ```json ` 标记，n8n 无法直接解析，需增加 `Code Node` 使用正则清洗并 `JSON.parse`。
2.  **n8n 表达式解析崩溃**：当 JSON 中嵌套复杂变量时，n8n 的 Expression 模式容易报错。解决方案是使用 `Code Node` 提前拼装好整个 JSON 对象，在 HTTP 节点中使用 `{{ $json }}` 原样发送。
3.  **飞书安全校验**：必须确保自定义机器人的“自定义关键词”与发出消息内容严格匹配。

## 🚀 如何使用
1. 将本仓库的 `expense-approval-workflow.json` 导入到你的 n8n 中。
2. 配置 DeepSeek API Key 凭证（Base URL 记得填 `https://api.deepseek.com/v1`）。
3. 在飞书群添加“自定义机器人”，获取 Webhook，并设置安全关键词为“审批”。
4. 在 HTTP 节点中替换你的 Webhook 地址，即可激活并测试。
